# Producto API

API REST desarrollada con Spring Boot para gestionar productos.

Este proyecto fue realizado como parte de la actividad calificable del Corte 2 de Desarrollo Fullstack. La aplicación implementa un CRUD completo utilizando arquitectura por capas y persistencia con JPA.

## Tecnologías

- Java 17
- Spring Boot 4.1.1
- Spring Web
- Spring Data JPA
- H2 Database
- Bean Validation
- Swagger / OpenAPI
- Maven
- Postman

## Estructura del proyecto

El proyecto utiliza arquitectura por capas:

```text
src/main/java/com/fullstack/productapi
│
├── controller
│   └── ProductoController.java
│
├── entity
│   └── Producto.java
│
├── repository
│   └── ProductoRepository.java
│
├── service
│   └── ProductoService.java
│
└── ProductoApiApplication.java
